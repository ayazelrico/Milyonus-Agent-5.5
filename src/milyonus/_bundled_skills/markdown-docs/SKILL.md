# Markdown Documentation
- **Headings:** `#`..`######` ; **emphasis** `**bold**`, `*italic*`, `` `code` ``
- **Lists:** `-` bullets, `1.` ordered, indent to nest
- **Code block:** ```` ```lang ... ``` ````
- **Table:** `| A | B |` + `|---|---|`
- **Link/image:** `[text](url)`, `![alt](path)`
- **Callout (GFM):** `> [!NOTE]` / `> [!WARNING]`
- README structure: title -> what/why -> install -> usage -> license
